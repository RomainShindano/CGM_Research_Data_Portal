CGM RESEARCH DATA PORTAL - LOCAL PROTOTYPE

HOW TO OPEN

1. Unzip CGM-Research-Data-Portal.zip.
2. Open the extracted CGM-Research-Data-Portal folder.
3. Double-click index.html.
4. If macOS asks which application to use, choose Google Chrome.

No installation, terminal command, Node.js, or web server is required.

WHAT WORKS

- Browse and select all eight country datasets.
- Complete the four-step access application.
- Simulate CGM approval.
- Accept the demonstration Data Use Agreement.
- Download the selected dummy country ZIP packages.
- Responsive desktop and mobile layouts.

PROTOTYPE LIMITATIONS

- Form entries are not transmitted, stored, or retained after refresh.
- The approval and agreement steps are simulated.
- All downloadable country packages contain dummy data only.
- The Welthungerhilfe logo is loaded from the existing CGM website and therefore
  requires an internet connection. The remainder of the prototype runs locally.

FILES

- index.html: page structure
- styles.css: all presentation and responsive styling
- app.js: selection, form, approval, agreement, and download interactions
- downloads/: eight dummy country packages
